<Lead>
  It's easy to get started. Just use the following commands to set up and start your first project:
</Lead>

```bash
npm create jeasx@latest
cd jeasx-quickstart
npm run dev
```

Hot reloading is enabled in `development mode`, allowing modified files to be automatically recompiled.

To run your project in `production mode`, you'll need to perform a build to export required metadata before starting the server:

```bash
export NODE_ENV=production
npm run build
npm start
```

Jeasx doesn't set `NODE_ENV=production` for you, so set it yourself for both the build and the server (see [environment variables](/configuration#environment-variables)).

You can create a new project with a specific name by providing an additional argument:

```bash
npm create jeasx@latest my-awesome-project
```

If your project is successfully started, just visit `http://localhost:3000/` in a browser of your choice. The dev server only listens on `localhost`. If you develop in a container or VM, start it with `HOST=:: npm run dev`.

You can visit a deployed version of the quickstart template at [https://quickstart.jeasx.dev](https://quickstart.jeasx.dev). The contents of the quickstart template can be found at [GitHub](https://github.com/jeasx/jeasx-quickstart).

<Highlight title="Which JavaScript runtime should I use?">
Jeasx is developed and tested extensively with the **latest LTS** version of [Node.js](https://nodejs.org/). Older versions are not supported, though they may work. Some examples in this documentation need Node.js 22 or newer (e.g. `Array.fromAsync`).

**Alternate JavaScript runtimes**

Jeasx is tested occasionally against [Bun](https://bun.sh) (`bun -b run [build|dev|start]`). Currently, no issues have been identified, and all Jeasx examples run as expected. Please note that support for alternative JavaScript runtimes is not guaranteed. If you encounter any issues, feel free to [report them](https://github.com/jeasx/jeasx/issues).

</Highlight>

<a id="docker"></a>

## Create a project with Docker support

If you want to use Docker, you can bootstrap a new project with additional resources (`Dockerfile`, `.dockerignore`) via the following flag:

```bash
npm create jeasx@latest -- --with-docker
```

<a id="vercel"></a>

## Create a project with Vercel support

If you are going to deploy your project on Vercel, you can bootstrap a project with additional resources (`vercel.json`, `api/vercel.js`) via the following flag:

```bash
npm create jeasx@latest -- --with-vercel
```

For the initial setup of a Jeasx project on Vercel, you should select `Other` as the `Application Preset`.
