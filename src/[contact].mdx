## Bug reports and feature requests

Found a bug or have an idea for an improvement? Please open an issue in the matching GitHub repository, so others can follow and join the discussion:

- **Jeasx core** (server, build, configuration): [github.com/jeasx/jeasx/issues](https://github.com/jeasx/jeasx/issues)
- **JSX runtime** (rendering, escaping, async components): [github.com/jeasx/jsx-async-runtime/issues](https://github.com/jeasx/jsx-async-runtime/issues)
- **This website and documentation**: [github.com/jeasx/jeasx-website/issues](https://github.com/jeasx/jeasx-website/issues)

A good bug report includes the Jeasx and Node.js versions you use, the steps to reproduce the problem, and what you expected to happen instead. A minimal example repository helps a lot.

## Contributions

Pull requests are welcome. For larger changes, please open an issue first, so we can discuss the approach before you invest your time.
