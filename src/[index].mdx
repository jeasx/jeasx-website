## Philosophy

Jeasx embraces modern HTML and CSS as the core building blocks for web development, complemented by server-side rendered asynchronous JSX. It provides the flexibility to seamlessly enhance functionality using JavaScript, empowering developers to create dynamic web sites with minimal resource consumption.

[Read more about the philosophy](/philosophy)

## Getting started

Start your project instantly with a single command, enabling seamless development with zero turnarounds.

```bash
npm create jeasx@latest
```
Whether you opt for a Node server, a Docker setup or a serverless environment, Jeasx provides the flexibility to deploy your application according to your preferences.
